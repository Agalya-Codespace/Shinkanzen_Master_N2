# 聴解 Ⅱ 練習1-C (p.22) · Claude's own practice set in the book's format (the book prints no script for CD A track 15)
N: 練習1のC。男の人の話を聞いて、実際はどちらか選んでください。
N: 例。
M: 今朝、寝坊して、会議に遅刻しちゃったよ。
-
N: 1番。
M: 昨日の試合、あと少しで負けるところだったよ。
-
N: 2番。
M: 駅まで走ったから、なんとか電車に間に合ってよかった。
-
N: 3番。
M: 週末のボランティア、参加したかったんだけど、仕事が入っちゃって。
-
N: 4番。
M: 北海道、行ってよかったよ。景色が最高だった。
-
N: 5番。
M: お客さんに電話をかけようとしたら、ちょうど向こうからかかってきたんだ。
-
N: 6番。
M: 部長に頼まれて、来週の会議の資料を作ることになったんだ。
-
N: 7番。
M: かばんに財布、入れたつもりだったんだけど、机の上に置いてきちゃった。
-
N: 8番。
M: 妻なら、今、買い物に出かけたところです。
-
N: 9番。
M: 電車で座ろうと思ってたんだけど、お年寄りが乗ってきたから、ずっと立ってたよ。
-
N: 10番。
M: 大事な書類、なくすところだったよ。タクシーに忘れそうになってね。
