# 聴解 Ⅰ-1 練習1-3 (p.15) · Claude's own practice set in the book's format (the book prints no script for CD A track 09)
N: 練習1の3。文を聞いて、それに対する返事の文を聞き、最もよいものを選んでください。
N: 例。
M: あした、びょういんへ行きます。
F: エー、どこか具合が悪いんですか。ビー、髪を切るんですか。シー、何を買うんですか。
-
N: 1番。
F: 来週、しけんなんです。
M: エー、おめでとうございます。ビー、しんけんですね。シー、がんばってくださいね。
-
N: 2番。
M: このコーヒー、ちょっとぬるいですね。
F: エー、もう少しさましましょうか。ビー、あたためなおしましょうか。シー、こいのにしましょうか。
-
N: 3番。
F: これ、きょうじゅうにお願いできますか。
M: エー、はい、きょうじゅに渡します。ビー、はい、夕方までにやります。シー、はい、きのうやりました。
-
N: 4番。
M: 先週の試合、せんしゅが、きゅうにんしか来なかったんだって。
F: エー、えっ、それで試合できたの？ビー、きゅうにこられても困るよね。シー、さんいになったんだね。
-
N: 5番。
F: このスープ、少し塩をたしてくれる？
M: エー、はい、だしますね。ビー、はい、これくらいでいい？シー、はい、ぬいでおきます。
-
N: 6番。
M: 新しいコート、あした、きようかな。
F: エー、今日は寒くないよ。ビー、きょうかなって、もう夜だよ。シー、あしたは雨らしいから、やめたほうがいいよ。
