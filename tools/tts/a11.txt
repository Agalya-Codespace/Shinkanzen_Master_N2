# 聴解 Ⅰ-2 練習2-2 (p.17) · Claude's own practice set in the book's format (the book prints no script for CD A track 11)
N: 練習2の2。文を聞いて、それに対する返事の文を聞き、最もよいものを選んでください。
N: 例。
M: このケーキ、食べちゃっていい？
F: エー、うん、どうぞ。ビー、うん、食べてたよ。シー、ううん、まだ食べてない。
-
N: 1番。
F: 宿題、まだやってないの？早くやんなきゃ。
M: エー、うん、もう終わっちゃった。ビー、わかってるよ。今やるところ。シー、やんなくてよかったね。
-
N: 2番。
M: 駅まで送ってこうか？
F: エー、ありがとう、助かる。ビー、うん、送っといたよ。シー、え、もう着いちゃったの？
-
N: 3番。
F: この本、明日までに読んどいてね。
M: エー、え、もう読んじゃったの？ビー、うん、読んどいてくれてありがとう。シー、わかった、今夜読んどく。
-
N: 4番。
M: あんまり無理しちゃだめだよ。
F: エー、うん、無理しちゃった。ビー、ありがとう、気をつける。シー、え、無理じゃないの？
-
N: 5番。
F: 窓、開けっぱなしで出かけちゃった。
M: エー、早く閉めに帰んなきゃ。ビー、開けといてくれたの？シー、出かけなくちゃね。
-
N: 6番。
M: このパソコン、すっごく高くって買えないよ。
F: エー、じゃ、買っちゃおうよ。ビー、もうちょっと安いのにしたら？シー、高くなくてよかったね。
